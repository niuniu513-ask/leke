# 乐课 · 在线课程学习助手（桌面端）

一个 Windows 桌面端的在线课程学习工具，基于 PySide6 构建，支持**学习通（超星）、雨课堂、智慧树、U校园**四个平台。

> **完全免费。** 软件没有任何付费项目，无套餐、无积分、无到期时间；账号长期有效。
> 仍需注册登录：云端共享题库、知识库与设备绑定挂在账号上。如果觉得好用，欢迎在「用户中心 → 支持作者」请作者喝杯奶茶（微信扫码，全凭自愿）。

## 功能

| 平台 | 能力 |
|---|---|
| 学习通 | 章节视频 / 文档 / 章节测验自动刷课；续刷熔断与进展判定；题面字体加密还原 |
| 课堂互动 | 签到（普通 / 签到码 / 手势 / 位置，含人脸与拍照）、主题讨论、评分、投票、问卷、随堂练习；新活动监控 |
| 雨课堂 | 视频 / 练习自动处理；课堂互动（正在上课读取、签到、PPT、答题） |
| 智慧树 | 视频链路（shared 协议） |
| U校园 | 内置 Edge 浏览器工作区，每账号独立会话；任务批处理与完成标记 |
| 答题 | 云端聚合题库 → 免费直连 → 本地知识库 → AI 兜底的多层回退；批改页正确答案自动回流知识库 |
| 账号 | 多账号管理、注册登录、设备绑定（同账号两台电脑）、云端知识库共享 |

桌面端做不了的事也会明说：例如学习通「二维码签到」的 enc 是老师端动态令牌，客户端无法获取，遇到时界面会提示用手机端完成。

## 下载与运行

- **普通用户**：从 [Releases](../../releases) 下载 `leke-x.y.z-win-x64.exe`（onefile，双击即用，用户数据生成在同目录）。
- **从源码运行**：Python 3.13 → 建虚拟环境 → `pip install -r requirements.txt` → `python 乐课.py`（Windows 可用 `启动乐课.bat`）。
- **打包**：`python build_exe.py --onefile`（需 PyInstaller）。
- **测试**：`python -m pytest -q`；桌面回归 `python tests/regression/_run_audit.py`（offscreen，21 个脚本）。

## 目录结构

- `api/`：四平台接口、答题策略、云端题库与知识库客户端。
- `gui_app/`：桌面页面、任务编排、主题样式。
- `resource/`：图标、字体映射表、U校园参考资料等运行期资源。
- `tests/`：单元测试 + 回归审计脚本。
- `config_template.ini`：首次启动配置模板（真实 `config.ini` 由程序生成，不入库）。

U校园使用内置 Edge 课程工作区，每个账号保留独立会话，可切换独立窗口（`python tests/regression/_test_browser_native.py` 本地验证，不提交课程）。

## 隐私与安全

- 源码库不包含任何用户账号、cookie、登录令牌、私钥或真实配置；账号档案 / cookie / 知识库均只落在本机，运行程序时重新登录或沿用本机原数据。
- 题库统一读写云端乐课服务，登录后自动导入原本地题库；原题库文件保留作为备份。
