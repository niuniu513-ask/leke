# 乐课 · 在线课程学习助手

把重复的听课流程自动化：多账号并行刷课、章节进度可视化、实时日志。
**所有数据都留在这台电脑上** —— 账号、密码、密钥、日志都在程序目录里，不上传任何地方。

---

## 一、怎么启动

### 方式 1：双击启动器（推荐）

双击目录下的 **`启动乐课.bat`** —— 它会用项目自带的 `.venv` 环境唤起窗口，不弹黑框。

想排查问题（需要看控制台输出）就用 **`调试运行乐课.bat`**。

### 方式 2：直接用打包好的 exe（免安装）

已经打好一份，双击这个就能用：

```
D:\学习通\学习通助手\乐课.exe
```

整个目录拷到别的电脑也能直接跑（免安装，不写注册表）。

> **只想更新程序时，替换 `乐课.exe` 这一个文件就够了。**
> 全部 Python 代码（界面 + 业务逻辑）都编译在这一个 exe 内部，
> `_internal\` 装的只是 Python 解释器与第三方库（PySide6、onnxruntime、opencv…），
> 日常改动不涉及它。只有升级依赖库版本时才需要连 `_internal\` 一起换。

要自己重新打包：

```bat
.venv\Scripts\python.exe build_exe.py
```

产物默认在 `dist\乐课\`；可用 `--distpath <目录>` 指定别处输出
（当旧目录被占用、覆盖失败时很有用）。

注意几点：

- 默认是 **onedir**（一个目录），启动快、出问题好排查。加 `--onefile` 可打成单文件，
  但体积更大、每次启动都要解压，不推荐。
- 体积偏大是正常的：依赖 `ddddocr` + `onnxruntime` + `opencv`，
  光这三个就带进来几百 MB 的二进制和模型文件，PyInstaller 必须收全，
  否则打包后验证码识别会失效。
- `config.ini`、`cookies.txt`、`leke.log`、`assets\` 都生成在 **exe 所在目录**，
  不在 exe 内部，方便随时手改。
- `assets\`（勾选图标、下拉箭头）是**首次启动时用代码画出来的 PNG**，
  QSS 的 `image` 不支持内嵌图片，所以必须落地成文件。
- 加 `--console` 参数可打成带控制台的版本，排查启动崩溃时用。

## 二、界面说明

左侧导航**一个平台一组**（v1.5.6 起），三个平台各有自己的识别色：

| 分组 | 页面 | 平台色 |
|---|---|---|
| **学习通** | 账号登录 / 课程列表 / 开始刷课 | 🔵 蓝 |
| **U校园** | 任务处理 | 🟠 橙 |
| **雨课堂** | 刷课 | 🟢 青绿 |
| **应用设置** | 参数设置 / AI 大模型 | ⚪ 中性灰（三个平台共用，不属于任何平台） |

「我在哪个平台」有三个地方能一眼看出来，不用去找：

1. 侧栏那一组的分组标题（带品牌色圆点，并且**只有该平台的页面**列在它下面）；
2. 顶栏左侧的**平台标签**（彩色小药丸，写着学习通 / U校园 / 雨课堂）；
3. 顶栏下方那条 **3 像素品牌色横线** —— 切页时整条线换色。

支持 **Ctrl+1 ~ Ctrl+7** 直接跳到对应页面（按从上到下的顺序编号，1 = 账号登录），
并且会自动记住你上次停留的页面，下次打开直接回到那里。

> 下面按「实际使用动线」讲，不完全是导航里的顺序。

---

### 1. 账号登录

**乐课支持同时登录多个账号，并行刷课，互不干扰。**

- 左侧是**账号列表**，右边是当前账号的详情表单。点「添加账号」新增一个。
- 每个账号有独立的 **cookies 文件**（`cookies_<id>.txt`，默认账号仍是 `cookies.txt`）、
  独立的会话、独立的课程勾选 —— 一个账号在跑，另一个照样能改设置。
- 填手机号和密码，点「登录」；想登录完直接进课程列表就点「登录并读取课程」。
- 勾选「保存账号密码到本机配置文件」后，下次打开会自动填好。
- 也可以用 **cookies 登录**：勾选该选项后，程序只读该账号的 cookies 文件，
  忽略上面的账号密码。cookies 需要你从浏览器导出后写到程序目录对应文件里。
- 账号档案存在 `accounts.json`，删除账号时 cookies 文件会改名保留（不硬删）。

### 2. 课程列表

- **顶部先选要看哪个账号**，再点「读取该账号的课程」拉取本学期课程，
  并**逐门统计章节完成进度**（进度条 + 待完成数）。
- 勾选要处理的课程。几个快捷按钮：全选 / 全不选 / 只选未完成的。
- **勾选结果按账号各自保存**，切换账号会自动恢复该账号上一次的勾选。
- **一门都不勾 = 处理该账号的全部课程**，开始时会再问一次。
- 课程 ID、班级 ID 也列出来了，方便对照。

### 3. 参数设置

分四个页签，全部直接读写程序目录的 `config.ini`（**原有注释和排版会完整保留**）：

| 页签 | 内容 |
|---|---|
| 运行参数 | 视频倍速、并发章节数、**视频学习模式**、遇到未开启章节的处理方式、失败重试等待、是否只处理未完成章节 |
| 题库 | 题库来源（provider）、token、自动提交与覆盖率、AI / 硅基流动 / TikuAdapter / GO 题 / LIKE 知识库的各自参数 |
| 通知 | Server 酱 / Qmsg / Bark / Telegram 推送，刷完或报错时通知你 |
| 高级 | 判断题词表、一键打开 config.ini / accounts.json / cookies.txt / 日志文件所在位置 |

几个要点：

- **题库 provider 留空 = 不使用题库**。此时章节测验会被跳过，有解锁要求的课程可能卡住。
- 填写多个 provider（英文逗号分隔）会按顺序回退查询，例如 `TikuGo,TikuYanxi,TikuLike`。

#### 任务点绿了，学习时长却是 0？（视频学习模式）

**现象**：视频任务点全部变成绿色「已完成」，但课程统计里的**学习时长几乎没涨**。

**原因**：平台是**按时间算时长**的。播放器每隔一会儿向服务器发一次心跳，
上报「我现在播到第几秒」；服务器拿**两次心跳之间的真实时间间隔**去和
**播放进度的增加量**比对，对得上才算有效学习时长。

默认的「快速完成」模式为了快，直接一次上报到视频结尾 —— 服务器看到的是
「0 秒内从第 0 秒跳到第 1940 秒」，于是**只给任务点，不给时长**。

**解决**：把「运行参数 → 视频学习模式」从「快速完成」改成 **「真实节奏」**。

| 模式 | 任务点 | 学习时长 | 耗时 |
|---|---|---|---|
| 快速完成（默认） | ✅ 立刻完成 | ❌ 几乎不涨 | 每个视频几秒 |
| 真实节奏 | ✅ 完成 | ✅ 正常累计 | ≈ 视频总长 ÷ 倍速 |

几个要注意的点：

- **倍速别开太高。** 服务器按 1 秒真实时间对 1 秒进度来算，2.0 倍速下平台通常只认一半时长。
  想要时长建议配 **1.0 倍**。
- **已经刷完的视频要重刷才有用**。任务点已完成时程序会**从头重播一遍**来补时长，
  所以要先把运行参数里的 **「只处理未完成的任务点」取消勾选**，否则那些章节会被直接跳过。
- **这一步没有捷径**。16 小时的课程想拿 16 小时时长，就得挂着 16 小时（想少花时间就把
  「同时处理的章节数」调大，让多个视频并行计时）。
- 顺带一提：平台一般只在 **7:00–23:00** 计入有效学习时长，且**同一账号不要手机电脑同时播放**。

#### 刷课只能刷一遍，剩下的章节没人管？（已修复）

**现象**：旧版刷完一遍就结束了，可课程进度还是不满 —— 明明还有章节能刷。

**原因**：很多课程是「**完成上一章的章节测验，下一章才解锁**」的链式结构。
章节列表是开跑前一次性读出来的，跑到后面遇到还没解锁的章节只能跳过；
等前面的章节测验做完了，那些章节早就被跳过去了，程序**不会回头再看一眼**。

**解决**：现在程序**会自己回来接着刷**，不需要你配置任何东西。

一遍处理完之后，程序会**重新向服务器读取一次章节列表**，把这一遍才解锁的章节
捞回来接着处理；再等一遍还是没有新东西可刷，才真正结束。

- 已经绿了的章节会被跳过，**不会重复刷**；
- 中途失败的章节会在下一遍重试；
- 连续 **2 遍**没有任何新完成的章节就收手（说明剩下的确实卡住了）；
- 极端情况下最多跑 **20 遍**兜底，防止死循环。

每个账号的进度卡上都有 `自动续刷` 徽标 —— 看到它一直在动，说明程序正在补刷，
不是卡住了。

> 配合「真实节奏」补学习时长时要留意：任务点已经绿了的视频，只有在
> **取消勾选「只处理未完成的任务点」**之后才会被重播，否则每一遍读到的都是空列表。

#### 用你自己的 API Key 答题（AI 大模型答题）

题库页签里有一块独立的 **「AI 大模型答题」** 面板，专门用来配置你自己的大模型密钥。
不需要注册任何第三方题库，只要有一个兼容 OpenAI 格式的接口就能用。

面板按**三步**走：

| 步骤 | 你要做的 |
|---|---|
| 第 1 步 选服务 | 点一张厂商卡片，**服务地址和默认模型会自动填好**。内置 16 家：DeepSeek、硅基流动、智谱 GLM、Kimi、阿里千问、豆包、腾讯混元、百度文心、MiniMax、小米 MiMo、讯飞星火、百川、OpenAI、Gemini、Grok、Claude（需中转），以及「自定义」 |
| 第 2 步 填密钥 | 粘贴访问密钥，点 **「检查是否能用」** |
| 第 3 步 启用 | 点 **「保存并使用」**，程序会把 `AI` 自动加到题库来源的最前面 |

几个实用细节：

- **「检查是否能用」会真的发一次请求**，告诉你三件事：能不能连通、密钥对不对、
  这个账号有哪些模型可选（可以点一下直接填入模型名）。
- 报错会翻译成人话，例如密钥错了提示「密钥无效或已过期，请重新复制」，
  账户没钱提示「余额不足」，地址写错提示「检查地址是否漏了 /v1」。
- 不确定模型名？留空也能点检查，程序会把账号可用的模型列出来。
- **服务地址填的是 `base_url`**，通常以 `/v1` 结尾（例如 `https://api.deepseek.com/v1`），
  不要填完整的 `/chat/completions` 地址。
- 要访问 OpenAI、Gemini、Grok 这些境外服务时，在第 2 步展开 **「显示高级选项」**，
  在 **「答题代理」** 里填你的代理地址（例如 `http://127.0.0.1:7890`）。
- **「请求最小间隔」**默认 3 秒，是给大模型限流用的，别调太小，容易触发 429。
- 密钥只写在**本机的 `config.ini`** 里，不会上传到任何地方。**别把这个文件连同目录发给别人。**

> 想省钱的话，DeepSeek、智谱（有免费模型）、硅基流动都有很便宜的档位；
> 章节检测的题量不大，正常一学期下来花费很低。

### 4. 开始刷课（完整说明）

> 导航里的「运行 → 开始刷课」就是这一页。

- 顶部勾选**参与刷课的账号**，可以多选，点「开始刷课」后它们并行跑。
  「停止」是整体软停，「停止全部」会停掉所有账号。
- **每个账号一张进度卡**，各自独立显示五个指标：**待刷章节 / 已处理 / 累计完成 / 失败 / 已用时**。
- 卡片里的进度区从下往上看就是「刷到哪了」：

  ```
  ▓▓▓▓░░░░░░░░░░░░░░      ← 进度条
  自动续刷 · 第 2 遍        ← 状态徽标
  尚未开始 / 本遍进度 4/12（33%）

  当前正在处理
  高等数学（上）             ← 课程
  第 3 章 微分中值定理与导数的应用   ← 章节
  [视频] 3.2 拉格朗日中值定理的应用.mp4  ← 正在处理的视频 / 测验 / 文档
  ▓▓▓░░░                  ← 本章节内的任务点进度
  本章节共 3 个任务点，正在处理第 2 个
  ```

- **「当前正在处理」会显示到具体视频名**，每一遍开始时自动重置。
- 每个任务点行下方是**浮点自绘的迷你进度条**：按墙钟连续滑动、显示
  `播放中 12:30 / 32:20 · 1.0x · 39%`，同一段播放内只增不减
  （v1.5.4 修复了此前"进度条一跳一跳"的观感问题）。
- 日志区在页面底部，支持显示详细日志（DEBUG 级）、自动滚动、清空、导出为 txt。
- **刷课期间顶栏会常驻「N 个账号刷课中」**：正在跑的任务用的是开始那一刻的
  配置快照，在参数设置 / AI 页临时改的值本轮不生效，停止后重新开始才应用。

### 5. U校园（其他平台 → U校园）

- 与学习通**完全独立**：账号存 `unipus_accounts.json`，用自己的 Edge 浏览器窗口跑。
- **支持多账号并存 + 并行**：页面顶部是账号条，点「＋ 新增账号」加号，
  账号条上的 **● 圆点**表示这个账号正在跑。
  「全部连接」会为每个账号各开一个 Edge 窗口（**验证码仍需人工完成**）；
  「全部停止」统一收手。
- 单账号操作：连上后点「扫描任务列表」，勾选要处理的单元，再点「处理选中任务」。
- AI 答题复用「**应用设置 → AI 大模型**」页里配置的那一份大模型；
  单个账号可以在自己的账号卡里填覆盖值（留空就用全局那份）。

### 6. 雨课堂（其他平台 → 雨课堂）

> 雨课堂 = 学堂在线 / 清华大学雨课堂，很多学校的课就挂在上面。
> 引擎来自开源项目 yuketangHelperBUU，vendor 化改造见 `api/yuketang/NOTICE.md`。

- **支持多账号并存 + 并行**：页面顶部是账号条，点「＋ 新增账号」加号
  （比如一人多个号）。每个账号可以填**不同的学校域名**。
  账号条上的 **● 圆点**表示正在刷课；「全部开始」= 所有已登录账号并行刷，
  「全部停止」统一收手。登录态存进 `yuketang_accounts.json`，下次打开不用重扫。
- 先在「学校域名」里填**你们学校的雨课堂域名**（例如 `buu.yuketang.cn`）。
  注意：雨课堂官网 `www.yuketang.cn` 用不了，必须是各校自己的域名。
- 点「**扫码登录**」，二维码会**直接画在本页里**（不会弹系统看图器），
  用微信扫一扫 → 确认登录即可。二维码约 60 秒自动刷新一次，
  下方实时显示走到哪一步（获取学校信息 → 等待扫码 → 校验登录 → 完成）。
- 扫码走不通时用「**用 cookie 登录**」兜底（详见常见问题）。
- 登录后点「**读取课程**」，勾选要处理的课程，再点「**开始刷课**」。
- 雨课堂的视频是**按心跳包上报**完成的，不需要真的播放视频，
  所以速度很快；进度卡会显示当前课程、当前视频和视频自身进度百分比。
- 「同时刷多个视频」默认关闭：并发更快，但更容易触发平台限流，
  跑得稳比跑得快重要。

## 三、文件说明

| 文件 | 作用 |
|---|---|
| `乐课.py` | 源码运行入口 |
| `启动乐课.bat` / `调试运行乐课.bat` | 启动器 |
| `build_exe.py` | PyInstaller 打包脚本 |
| `gui_app/` | 界面与调度代码 |
| `api/` | 平台核心：学习通（`base.py` 等）+ vendor 引擎（`unipus/`、`yuketang/`） |
| `tests/regression/` | 回归套件（纯离线，脚本数与断言数见各脚本末尾自报） |
| `accounts.json` | 学习通多账号档案（备注名 / 手机号 / 各账号勾选课程，自动生成） |
| `unipus_accounts.json` | U校园多账号档案（账密 / token / AI 覆盖项，自动生成） |
| `yuketang_accounts.json` | 雨课堂多账号档案（域名 / cookie / user_id，自动生成） |
| `*.json.migrated` | 旧单账号文件（`unipus.json` / `yuketang.json`）升级时自动迁移后的遗留，可以删 |
| `gui_settings.json` | 界面偏好（窗口大小、上次停留的页面等，自动生成） |

`gui_app/` 内部分工：

```
app.py            入口：接管输出流 -> 切工作目录 -> 起窗口
main_window.py    主窗口：侧栏导航、状态栏、日志分发、业务串联
worker.py         后台线程：按账号独立跑登录 / 拉课程 / 刷课，Qt 信号回主线程
study_engine.py   可停止的章节调度器（逐章节逐任务点派发）
profiles.py       多账号档案：accounts.json 读写、各账号 cookies 路径
store.py          config.ini 读写（文本级替换，保留注释）+ 界面偏好
stream.py         把 stdout/stderr 接管到界面，区分日志行与 tqdm 进度条
theme.py          浅色主题调色板与全局 QSS
widgets.py        卡片 / 徽标 / 指标块 / 表格委托等通用组件
icons.py          内置矢量图标库（内嵌 SVG，不依赖外部图片）
ai_panel.py       AI 答题配置面板（三步向导 + 连通性检测，后台线程跑）
ai_providers.py   厂商目录：名称 / 服务地址 / 默认模型 / 申请密钥的页面
ai_icons.py       厂商图标（内嵌 SVG，构建期生成）
unipus_engine.py  U校园适配层：Selenium/Edge 引擎、后台线程、信号回抛
yuketang_engine.py 雨课堂适配层：扫码登录、心跳刷课、后台线程
page_account.py   账号登录页        page_courses.py  课程列表页
page_run.py       开始刷课页        page_settings.py 参数设置页
page_ai.py        AI 大模型页       page_unipus.py   U校园页
page_yuketang.py  雨课堂页
```

> 主窗口的导航是**数据驱动**的：`main_window.NAV` 是唯一数据源，
> 页面栈顺序、跳转、Ctrl 快捷键都从它派生，加页面只改 NAV 一处。

## 四、常见问题

**Q：双击 bat 提示找不到 .venv？**
说明虚拟环境没建好。在项目目录执行：

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pip install PySide6-Essentials -i https://mirrors.aliyun.com/pypi/simple/
```

**Q：界面里日志不刷新 / 一片空白？**
日志走 loguru，乐课在启动最早期接管了输出流。若你改过 `gui_app/app.py`
的启动顺序（把 `stream.install()` 挪到 import 之后），日志就会丢 —— 顺序不能动。

**Q：点「开始刷课」提示未配置题库？**
去「参数设置 → 题库」填 provider 和对应 token。没有题库时章节测验会被跳过。

**Q：视频任务点全绿了，可课程学习时长还是 0？**
因为默认的「快速完成」模式是**一次跳到视频结尾**，服务器只认任务点、不算时长。
把「运行参数 → 视频学习模式」改成 **「真实节奏」**，并取消勾选「只处理未完成的任务点」
（否则已完成的视频会被跳过，没法补时长）。

**Q：刷完一遍就停了，后面的章节还是没刷？**
新版不会了。有些课程是「做完上一章的章节测验才解锁下一章」，而章节列表是开跑前读的，
早先的版本读到没解锁的章节就跳过，之后再也不会回头看 —— 现在的程序每一遍处理完都会
**重新读一次章节列表**，把新解锁的章节接着处理，直到连续两遍都没新东西可刷才结束。

**Q：多账号会不会互相影响？**
不会。每个账号一份独立会话、独立 cookies 文件、独立课程勾选，各跑各的线程。
U校园、雨课堂也都是多账号（分别存 `unipus_accounts.json` / `yuketang_accounts.json`），
与学习通完全隔离：三个平台的登录态互不影响，各跑各的。

**Q：雨课堂扫码后没反应 / 登录不上？**
按顺序排查，**先看页面下方的登录步骤停在哪一步**（登录全过程都会写进 `leke.log`）：

1. **学校域名**必须是你们学校自己的雨课堂域名（如 `buu.yuketang.cn`）。
   官网 `www.yuketang.cn` **不支持**这种登录方式。
   停在「获取学校信息」= 域名错或网络不通。
2. 二维码约 60 秒刷新一次，**看到二维码再扫**；扫码用的微信必须
   **已绑定你们学校的雨课堂账号**（没绑定的话服务端会拒绝换发登录态）。
   停在「等待扫码」基本就是这个原因。
3. 停在「校验登录」= 服务端拒绝了，界面会把**服务端原话**显示出来，
   照着提示处理即可（常见是微信没绑定，或学校网关拦了请求）。
4. **还不行就用 cookie 兜底**（不依赖扫码，通常一次就过）：
   电脑浏览器登录雨课堂网页版 → F12 → Network → 随便点一个请求 →
   把 Request Headers 里的 `Cookie:` 整行复制出来（**必须包含 `sessionid=`**），
   粘到页面的「用 cookie 登录」里。
5. 新版首次启动会自动把旧的 `yuketang.json` 迁移进 `yuketang_accounts.json`
   （旧文件改名成 `.migrated`），原来的登录态不会丢。

**Q：雨课堂刷课会不会很慢？**
不会。雨课堂视频是按**心跳包**上报完成的，不需要真的播放，
比学习通那边的「真实节奏」模式快得多。

**Q：顶栏一直显示「N 个账号刷课中」，改设置没用？**
这是有意为之：正在跑的任务用的是**开始那一刻的配置快照**。
在参数设置 / AI 页临时改的值本轮不生效，**停止后重新开始**才会应用。
刷课期间运行页的「从头重刷」等配置控件也会一并置灰。

**Q：侧栏的 Ctrl+1..7 是什么？**
跳到对应页面的快捷键，编号按侧栏从上到下的顺序（1 = 开始刷课）。
程序还会记住你上次停留的页面，下次打开直接回到那里。

**Q：一直提示「登录失败」，登不上去？**
先别急着重抓 cookies —— 多数情况是**网络/代理断了**，不是账号问题。程序会直接把
原因翻译成中文：

| 界面提示 | 真正的问题 | 怎么办 |
|---|---|---|
| 无法解析服务器域名（DNS 失败） | 电脑解析不出域名 | 检查网络；关掉或切换代理节点；必要时重启电脑 |
| 连接被拒绝 / 代理连接失败 | 代理端口没在监听 | 打开代理软件，或干脆关掉代理直连 |
| 连接超时 | 网络或代理不通 | 换节点 / 关代理 / 稍后重试 |
| 要求输入验证码 | 账号被要求人机验证 | 先在手机「学习通」App 正常登录一次，或改用 cookies 登录 |
| cookies 已失效，请更新 | cookie 真的过期了 | 重新导出一份 cookies |

排查顺序（从便宜到贵）：

1. 浏览器能不能打开学习通登录页 —— 打不开就是网络问题；
2. 代理软件是否正常（端口开着但没转发，同样会「连不上」）；
3. 在「账号登录」页取消勾选「使用 cookies 登录」，用手机号 + 密码试一次；
4. 仍然不行，看 `leke.log` 最后几行，或把提示原文发出来。

**Q：能一边刷课一边关窗口吗？**
点关闭会拦一下确认。确认后程序退出，当前任务点会中断。

**Q：为什么不直接双击 `乐课.py`？**
Windows 默认会用系统 Python 打开，而依赖装在项目 `.venv` 里，会报找不到 PySide6。
用 `.bat` 启动器，或打包成 exe。
