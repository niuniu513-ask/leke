# 乐课 · 在线课程学习助手（Windows 桌面端）

一个 Windows 桌面端的在线课程学习工具，基于 PySide6 构建，支持**学习通（超星）、雨课堂、智慧树、U校园**四个平台。

> 本项目**闭源发布**，仓库只作项目介绍，不含源码。

## 功能一览

| 平台 | 能力 |
|---|---|
| 学习通 | 章节视频 / 文档 / 章节测验自动刷课；续刷熔断与进展判定；题面字体加密还原 |
| 课堂互动 | 签到（普通 / 签到码 / 手势 / 位置，含人脸与拍照）、主题讨论、评分、投票、问卷、随堂练习；新活动监控 |
| 雨课堂 | 视频 / 练习自动处理；课堂互动（正在上课读取、签到、PPT、答题） |
| 智慧树 | 视频链路 |
| U校园 | 内置 Edge 浏览器工作区，每账号独立会话；任务批处理与完成标记 |
| 答题 | 云端聚合题库 → 免费直连 → 本地知识库 → AI 兜底的多层回退；批改页正确答案自动回流知识库 |
| 账号 | 多账号管理、注册登录、设备绑定（同账号两台电脑）、云端知识库共享 |

桌面端做不了的事也会明说：例如学习通「二维码签到」的 enc 是老师端动态令牌，客户端无法获取，遇到时软件会提示用手机端完成。
